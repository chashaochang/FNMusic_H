# Template provenance

This project was assembled from the API 26 templates bundled with DevEco Studio 3 because the IDE does not expose a supported headless project-creation command.

Template sources:

- `/Applications/DevEco-Studio 3.app/Contents/plugins/openharmony/lib/templates/project/New Project`
- `/Applications/DevEco-Studio 3.app/Contents/plugins/openharmony/lib/templates/module/New Module`
- `/Applications/DevEco-Studio 3.app/Contents/plugins/openharmony/lib/templates/ability/Empty Ability`

Applied parameters:

- Project type: Application
- UI model: Stage
- UI syntax: ArkTS
- Module: `entry`
- Ability: `EntryAbility`
- Device type: phone
- Model version: `26.0.0`
- Target SDK: `26.0.0`
- Compatible SDK: `26.0.0`
- Bundle name: `cn.xiaobai.feiniumusic`

The project structure comes from the templates above. Product implementation
was developed for this client while consulting the public projects documented
in `THIRD_PARTY_NOTICES.md`. No Android APK, decompiled source, captured private
application bundle, or proprietary Feiniu artwork is included in this repository.
